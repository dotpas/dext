API Details

record TArgMatcher

An argument matcher captured by an Arg method, together with the type it was declared for. The type lets the mock place the matcher on the right parameter when matchers and literal values are mixed.

class TMatcherFactory

Inherits from: TObject
Storage for argument matchers. Matchers registered via Arg methods are captured when a method is called during setup, allowing the mock to later match actual call arguments.
