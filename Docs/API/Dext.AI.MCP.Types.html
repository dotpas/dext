record TMCPToolResult

Result returned by MCP tool callbacks. Factory methods: TMCPToolResult.Text('plain text') - success, one text item TMCPToolResult.Error('something failed') - error result TMCPToolResult.Image(b64, 'image/png') - success, one image item TMCPToolResult.Audio(b64, 'audio/mpeg') - success, one audio item TMCPToolResult.Resource(uri, text) - success, embedded resource Multiple content items: var R := TMCPToolResult.Text('caption'); R.AddContent(TMCPContent.Image(b64, 'image/png'));

type TMCPContentType = enumeration
Values: mctText, mctImage, mctAudio, mctResource
Discriminated type tag for MCP content items.
type TMCPToolResultCallback = Type
Rich tool callback - return TMCPToolResult instead of a plain string. Preferred over TMCPToolCallback for multi-content and error signalling.
type TMCPResourceReadCallback = Type
Callback invoked on resources/read - receives URI, returns contents.
type TMCPPromptGetCallback = Type
Callback invoked on prompts/get - receives template arguments.
