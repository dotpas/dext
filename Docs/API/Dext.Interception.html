interface IInvocation

Represents a method invocation that has been intercepted. Provides access to the method metadata, arguments, and result.
PUBLIC
function GetMethod: TRttiMethod
Returns the RTTI method being invoked.
function GetArguments: TArray
Returns the arguments passed to the method.
function GetResult: TValue
Returns the current result value.
procedure SetResult(const const: TValue)
Sets the result value to return from the method.
function GetTarget: TValue
Returns the target instance if proxying with target.
procedure Proceed
Proceeds to the next interceptor in the chain, or to the target method if this is the last interceptor.
property Method:
The RTTI method being invoked.
property Arguments:
The arguments passed to the method (modifiable for var/out params).
property Result:
The return value of the method.
property Target:
The target instance (nil for proxies without target).
