record TMCPToolParam

Describes a single input parameter for an MCP tool.

function TypeName: string
Returns the JSON Schema type string.

record TMCPToolDef

Full definition of an MCP tool (name, description, params, handlers). ResultCallback takes precedence over Callback when both are set. Use ResultCallback for rich content (image, audio, embedded resource) or for explicit isError signalling.

class TJsonRpc

Inherits from: TObject
JSON-RPC 2.0 response builder. All methods produce a self-contained JSON string ready to send. The JSON-RPC "id" (string | number | null) is represented as an IDextJsonNode. Pass nil for a missing/absent id.
PUBLIC
function Success(const const: IDextJsonNode; const const: string): string
Builds a success response. ResultJson is a raw JSON string that will be embedded as the "result" value.
function Success(const const: IDextJsonNode; const const: TJsonObject): string
Builds a success response from an already-built TJsonObject. Ownership of ResultObj is NOT taken - caller still frees it.
function Error(const const: IDextJsonNode; Code: Integer; const const: string): string
Builds an error response.
function GetId(const const: TJsonObject): IDextJsonNode
Extracts the "id" field from a JSON-RPC request object. Returns nil if the "id" key is absent or null.

Types

type TMCPParamType = enumeration
Values: ptString, ptInteger, ptNumber, ptBoolean, ptObject, ptArray
Supported JSON schema types for tool parameters.
type TMCPToolCallback = Type
Legacy tool handler callback - returns a plain string. The string can be plain text or a JSON payload; it is sent as text content. New code should prefer TMCPToolResultCallback (rich content + error flag).
