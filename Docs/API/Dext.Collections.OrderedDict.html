interface IOrderedDictionary<K, V>

Inherits from: IDictionary
Generic interface for an insertion-ordered dictionary. Behaves like IDictionary<K,V> but enumeration and the Keys/Values projections always reflect the order in which keys were first added, and elements can be reached by their 0-based position.
PUBLIC
