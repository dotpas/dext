record TJsonUtils

Utilities for JSON manipulation, including casing.
PUBLIC
function ToCamelCase(const const: string): string
function IsDateType(AType: PTypeInfo): Boolean
True for TDateTime, TDate and TTime.
function DateToJsonText(const const: TDateTime; AType: PTypeInfo; const const: TJsonSettings): string
The JSON text of a date, the same on every path. With TDateFormat.ISO8601 (the default) the standard (RFC 3339 / ISO 8601): a TDateTime is the local time with its UTC offset ("2026-07-15T10:30:00.000+02:00", Dext.Core.DateUtils.FormatJsonDateTime), a TDate the calendar day ("2026-07-15"), a TTime the wall clock ("10:30:00.000"). Otherwise FormatDateTime(ASettings.DateFormat), as before (records write TDateFormat.UnixTimestamp as a number).
function IsNoDate(const const: TDateTime; AType: PTypeInfo; const const: TJsonSettings): Boolean
True when a date is written as null: a TDateTime or TDate that is 0 ("no date") with ZeroDateAsNull, the default, or one of the NullDates. A TTime never is: 0 is midnight there. Every path that writes a date asks this first.
function TryJsonTextToDate(const const: string; AType: PTypeInfo; out out: TDateTime): Boolean
Reads a JSON date for a TDateTime, TDate or TTime: the standard forms first (a 'Z' or an offset is converted to local time, no zone is local time; Dext.Core.DateUtils.TryParseJsonDateTime / TryParseJsonTime), then the other forms TryParseCommonDate knows. A TDate keeps the day, a TTime the time of day.
function ToPascalCase(const const: string): string
function ToSnakeCase(const const: string): string
function ApplyCaseStyle(const const: string; Style: TCaseStyle): string
function IsReadableDateFormat(const const: string): Boolean
True when a [JsonFormat] date format can be read back: made of yyyy yy mm m dd d hh h nn n ss s zzz z and of fixed text (in quotes, or characters that are not letters). Month and day names, am/pm and the other FormatDateTime letters are written but cannot be read.
function TryParseDateWithFormat(const const: string; const const: string; out out: TDateTime): Boolean
Reads AText with a [JsonFormat] date format (see IsReadableDateFormat): the digits of each part, the fixed text equal. A part the format does not have takes the value of 1899-12-30 00:00. False when the text does not match or is not a valid date or time.
function SmartRecordFieldName(const const: string): string
The JSON name of a record field under SmartRecordMapping. A backing field, 'F' followed by an uppercase letter or '_' (FName, FValue, F_Note), loses the 'F'; any other name is left as it is (Flag, Format, Fee, Fattura). One rule for the record plan and GetFieldName.
function IsBytesType(AType: PTypeInfo): Boolean
True for a byte array: TBytes, TArray<Byte> or any other dynamic array of Byte. In JSON it is binary data, written as Base64.
function BytesToBase64(const const: TBytes): string
Base64 on one line, with padding (RFC 4648, TNetEncoding.Base64String): not the MIME form, which breaks the line every 76 characters.
function BytesToBase64(AData: Pointer; ASize: Integer): string
function TryBase64ToBytes(const const: string; out out: TBytes): Boolean
Base64 (RFC 4648) to bytes. Also accepted: without the final '=', with line breaks and spaces (the MIME form), and the URL alphabet ('-' and '_'). False for any other character, the two alphabets mixed, a '=' that is not at the end, or an impossible length, so that a text that is not Base64 is not turned into random bytes. An empty text is an empty array.

record TJsonFieldFormat

The format attributes of a field or property: [JsonFormat], [JsonString], [JsonNumber], [JsonBoolean] (#262). They work the same on classes and records, when writing and when reading; the plan checks them when it is built (Validate).
PUBLIC
function IsSet: Boolean
True when one of the four attributes is present.
function FromAttributes(const const: TArray): TJsonFieldFormat

procedure Validate(AType: PTypeInfo; const const: string; const const: string)
Raises EDextJsonException when the attributes cannot work on AType: more than one of them, [JsonFormat] not on a date or with a format that cannot be read back, [JsonString] not on a number or Boolean, [JsonNumber] not on a string, [JsonBoolean] not on an integer.
