class TMCPToolProvider

Inherits from: TObject
Base class for class-based MCP tool providers. Subclass, annotate public virtual methods with [MCPTool] + [MCPParam], then call Server.RegisterProvider(TMyProvider.Create). The registry takes ownership of the provider instance.
PUBLIC
procedure BeforeCall(const const: string; const const: TJsonObject)
Called before each tool invocation. Override for logging/auth.
procedure AfterCall(const const: string)
Called after each successful tool invocation.

interface IMCPToolBuilder

Fluent builder for configuring an MCP tool before registering it. Chain: .Description / .Param / .OnCall (or .OnCallResult). The tool is committed to the registry when OnCall / OnCallResult is invoked.
PUBLIC
function Description(const const: string): IMCPToolBuilder
function Param(const const: string; const const: string; AType: TMCPParamType; ARequired: Boolean): IMCPToolBuilder
function OnCall(ACallback: TMCPToolCallback): IMCPToolBuilder
Registers a legacy string callback. Use OnCallResult for new tools.
function OnCallResult(ACallback: TMCPToolResultCallback): IMCPToolBuilder
Registers a rich-result callback. Preferred over OnCall.
