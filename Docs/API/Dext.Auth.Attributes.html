class AuthorizeAttribute

Inherits from: TCustomAttribute

class AuthorizePolicyAttribute

Inherits from: AuthorizeAttribute
Requires authentication and evaluates a named authorization policy. Use this instead of named arguments (Delphi has no Policy = syntax). Does not collide with (roles/scheme).
PUBLIC
constructor Create(const const: string)
Initializes a new instance requiring the given policy name.

class AllowAnonymousAttribute

Inherits from: TCustomAttribute
Marks a handler or controller as allowing anonymous access (bypasses authentication).
