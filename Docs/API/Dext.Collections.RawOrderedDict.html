class TRawOrderedDictionary

Inherits from: TObject
Non-generic hash map that preserves insertion order. Backed by a TRawDictionary (Key -> position) plus two ordered TRawList storages (keys and values). Keys are held both in the index and in the order list, trading a little memory for full reuse of the tested probing/comparer backend.
