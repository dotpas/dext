function FormatJsonDateTime(const const: TDateTime): string
A TDateTime as JSON text, RFC 3339 / ISO 8601: the LOCAL time with its offset from UTC, "2026-07-15T10:30:00.000+02:00" ("Z" when the offset is zero). The digits are the wall clock, so a reader that ignores the offset still shows 10:30; the offset gives the instant, also in the hour that repeats when daylight saving time ends. The offset is taken in whole minutes and kept per calendar year (per thread): the system is asked about 25 times for a year, to find the days the offset changes on, not for each value, however far apart the values are. On the two days around a change, and before 1900, it is asked for each value. A local time that does not exist (in the hour skipped when daylight saving time starts) takes the offset the system gives it.

function TryParseJsonDateTime(const const: string; out out: TDateTime): Boolean
Reads a JSON date and time as LOCAL time. Accepted: "yyyy-mm-dd", and "yyyy-mm-ddThh:nn[:ss[.fff]]" (also with a space instead of 'T') with an optional zone: 'Z' or an offset (+hh:mm, +hhmm, +hh) is converted to the local time of this machine; no zone is local time already. False for anything else.
function TryParseJsonTime(const const: string; out out: TDateTime): Boolean
Reads a JSON time of day: "hh:nn[:ss[.fff]]" (a zone after it is ignored: a time of day has none), or a whole date and time, of which the local time of day is taken. False for anything else.
