The worker threads the engine starts: IoThreadCount, or four per logical processor when it is 0.
function HttpSysReceiveCount(const const: TServerEngineOptions; AWorkers: Integer): Integer
The receives the engine keeps posted for AWorkers workers: OutstandingReceives when set; otherwise AWorkers x OutstandingReceiveDepth (1..8) when IoThreadCount is set, as before; otherwise (the default) one per logical processor, and OutstandingReceiveDepth is not used.
