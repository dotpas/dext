Unit Dext.MM

Global Routines

Routines
procedure EnableMemoryLeakReporting
Enables memory leak reporting on application shutdown. Only effective when FastMM5 is enabled via DEXT_USE_FASTMM5 define. With DEXT_USE_MIMALLOC there is no leak report: the report belongs to the RTL memory manager, which then holds no block. Use mimalloc for release builds and the default manager to look for leaks.
procedure DisableMemoryLeakReporting
Disables memory leak reporting on application shutdown.
function IsFastMMEnabled: Boolean
Returns True if FastMM5 is active (DEXT_USE_FASTMM5 is defined).
function IsMiMallocEnabled: Boolean
Returns True if mimalloc is the memory manager of the process: DEXT_USE_MIMALLOC is defined and Dext.MM installed it. It is not installed when another unit allocated before Dext.MM (Dext.MM is then not the first unit): a block allocated by the RTL manager and freed by mimalloc would corrupt the heap, so the RTL manager stays.
function MiMallocVersion: Integer
The version of the loaded mimalloc (for example 252 for 2.5.2), or 0 when mimalloc is not active.
